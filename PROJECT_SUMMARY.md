# Project Summary

## Resume Positioning

Customized a Claude Context semantic code-search system for local-first development by configuring Ollama embeddings, Milvus vector storage, MCP integration, and VSCode extension defaults.

## What This Project Demonstrates

- MCP server integration for AI coding assistants.
- Semantic code search over indexed codebases.
- Local embedding generation with Ollama (`nomic-embed-text`) instead of requiring OpenAI by default.
- Vector search storage through local Milvus or optional Zilliz Cloud.
- Multi-platform packaging across core library, MCP server, VSCode extension, and Chrome extension.
- Developer-focused documentation and setup scripts for reproducible local demos.

## Suggested CV Bullet

Adapted an open-source MCP semantic code-search tool into a local-first developer assistant using Ollama embeddings, Milvus vector storage, VSCode integration, and configurable provider backends for privacy-preserving codebase retrieval.

## Attribution Note

This repository is based on the open-source `zilliztech/claude-context` project. CV and portfolio descriptions should frame the work as customization, local-first configuration, and integration rather than a from-scratch implementation.
